# Security Policy

If you discover a security issue in this project, please report it privately instead of opening a public issue.

Please contact the repository owner through the GitHub account or preferred security contact and include:

- a concise description of the issue
- the affected repository or component
- reproduction steps where possible
- any relevant screenshots or logs

Please do not disclose sensitive details in public issues, pull requests, or commit messages.

This project should not contain production secrets, internal credentials, or live database connection strings in version-controlled files.
