# Contributing

Contributions are welcome when they improve the quality, clarity, or maintainability of the project.

## Before contributing

- keep changes focused and relevant
- document notable setup or configuration changes
- avoid committing credentials, secrets, or production environment values
- prefer clear, readable code and concise documentation

## Pull requests

Open a pull request with a clear description of:

- what changed
- why it changed
- how it was tested or validated

## Notes

This is a personal portfolio project, so contributions should remain aligned with the project’s purpose and professional presentation.
